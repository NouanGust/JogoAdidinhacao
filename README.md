# Palavra Secreta

Projeto desenvolvido durante as aulas do **RenovaTech**, um programa de capacitação em tecnologia e desenvolvimento de software.

## Sobre o projeto

Palavra Secreta é um jogo de adivinhação de palavras desenvolvido com HTML, CSS e JavaScript puros. O jogador recebe dicas progressivas e tem um número limitado de tentativas para descobrir a palavra secreta. A cada erro, uma nova dica é revelada. Ao esgotar todas as tentativas, o jogo reinicia automaticamente.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)

## Temas abrendidos

### HTML
- Estrutura semântica de uma página web (`header`, `main`, `footer`)
- Elementos de formulário: `input` e `button`
- Atributos de eventos inline (`onclick`, `onmouseenter`)
- Vinculação de arquivos externos de CSS e JavaScript

### CSS
- Box model e o uso de `box-sizing`
- Flexbox para alinhamento e distribuição de elementos
- Estilização de inputs e botões
- Posicionamento com `position: fixed`
- Pseudo-elementos e pseudo-classes (`:hover`, `::placeholder`)
- Uso do CSS Reset para garantir consistência entre navegadores
- Organização de estilos com seletores aninhados

### JavaScript
- Manipulação do DOM com `document.getElementById`
- Seleção e manipulação de propriedades como `innerText` e `textContent`
- Trabalho com arrays de objetos
- Funções e escopo de variáveis (`let`)
- Lógica condicional com `if` / `else`
- Geração de números aleatórios com `Math.random()` e `Math.floor()`
- Recarga de página com `location.reload()`
- Eventos de usuário acionados via HTML

## Como executar

Não é necessário instalar nenhuma dependência. Basta abrir o arquivo `index.html` diretamente no navegador.

```
git clone https://github.com/NouanGust/palavra-secreta.git
cd palavra-secreta
# Abra o index.html no seu navegador
```
